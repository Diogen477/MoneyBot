# MoneyBot — Telegram-бот для учёта расходов

> Версия: 1.0.2-beta

Персональный Telegram-бот для ведения учёта трат с поддержкой категорий, отчётов, повторяющихся платежей и свободного формата ввода.

## ✨ Возможности

- **Свободный ввод трат** — пиши как удобно: `Продукты яблоки 100`, `такси 500`, `Еда 1200р`
- **Гибкий точный формат** — разделители `,` или `|`: `Продукты, Яблоки, 100, 2` или `Еда | пицца | 500`
- **Умная категоризация** — нечёткий поиск категорий (≥55% сходства), запоминание последней использованной, предложение создать новую с отображением имени
- **Объединение категорий** — слияние нескольких категорий в одну с переносом всех трат и шаблонов
- **Отмена** — inline-кнопка «↩ Отменить» после каждой записи
- **Детальные отчёты** — по категориям, за период, все траты — с группировкой, детализацией и HTML-форматированием
- **Визуализация** — круговые диаграммы, stacked bar charts с линией тренда, интерактивная детализация
- **Excel-экспорт** — полные отчёты в формате .xlsx с группировкой по категориям
- **Редактирование и удаление трат** — через меню «Сервис» с выбором периода
- **Шаблоны** — повторяющиеся траты (аренда, подписки) с ежедневными напоминаниями в локальное время
- **Ежемесячное сравнение** — автоматический отчёт 1-го числа: сравнение с прошлым месяцем по категориям
- **Мультивалютность** — KZT, RUB, USD, EUR, UAH, GBP, UZS, KGS
- **Часовой пояс** — индивидуальная настройка для каждого пользователя, напоминания приходят в локальное 9:00

## 🚀 Что нового в 0.6.0-beta

- ✅ **Поддержка разделителя `|` (прочел)** — теперь можно вводить траты как `Еда | пицца | 500` при редактировании и добавлении
- ✅ **Улучшенное создание категорий** — кнопка отображает `➕ Создать «Продукты»` вместо общего текста

- ✅ **Case-insensitive поиск** — категории "Продукты" и "продукты" корректно определяются как одна

# 📖 Инструкция пользователя

## Начало работы

1. Отправьте боту `/start`
2. Бот закрепит сообщение с примерами формата ввода
3. Создайте первые категории через **Категории → Добавить категорию**
4. Начните вводить траты!

## 💰 Добавление трат

### Свободный формат

Просто напишите трату как удобно:

```
Продукты яблоки 100
Такси 500
Еда пицца 1200р
Кафе кофе 800тг
транспорт метро 150сом
```

Бот найдёт категорию по первому слову (в том числе **нечётким поиском** с порогом 55%), распознает сумму и запишет трату.

### С ценой и количеством

Если указать два числа, бот посчитает сумму автоматически:

```
Продукты молоко 350 2
```

**Результат:** Продукты — молоко, 350 × 2 = 700 ₸

### Точный формат (с разделителями)

**Разделитель `,` (запятая):**
```
Продукты, Яблоки, 100, 2
Такси, 500
```

**Разделитель `|` (прочел):**
```
Еда | пицца | 1200
Транспорт | метро | 150 | 2
```

Оба разделителя работают одинаково — выбирайте удобный!

### Быстрый ввод без категории

Если написать трату без категории:

```
кофе 450
```

Бот предложит записать в последнюю использованную категорию:

> Записать «кофе 450 ₸» в категорию «Еда»?
>
> [ Да ] [ Другая ]

- **Да** — записывает в предложенную категорию
- **Другая** — показывает список категорий для выбора

### 🔍 Нечёткий поиск категорий (Fuzzy Search)

Бот использует алгоритм нечёткого поиска с порогом **55% сходства**. Если категория не найдена точно, бот ищет похожую:

**Пример:**
Вы пишете: `Ееда 500`
Категория называется: `Еда`

Бот предложит:

> Категория «Ееда» не найдена, но есть «Еда». Использовать её?
>
> [ ✅ Да, использовать ] [ ➕ Создать «Ееда» ] [ ◀️ Назад ]

**Новое в 0.6.0:** Кнопка создания категории теперь показывает имя: `➕ Создать «Ееда»`

Если похожей категории нет, бот предложит создать новую с указанным именем.

### ↩ Отмена траты

После каждой записи появляется кнопка **↩ Отменить**. Нажмите, чтобы удалить ошибочную трату.

⚠️ **Внимание:** Кнопка работает только для последней траты — после новой записи предыдущую отменить можно только через **Сервис → Удалить траты**.

## 📁 Категории

Нажмите **Категории** в главном меню:

```
[  Мои категории  ] [ Добавить категорию ]
[ Удалить категорию] [ Объединить категории]
[                Назад                    ]
```

### Мои категории

Показывает список всех категорий с ID:

```
1: Продукты
2: Транспорт
3: Еда
4: Развлечения
```

### Добавить категорию

Введите название новой категории. Регистр не важен — `Продукты` и `продукты` будут считаться одной категорией.

### Удалить категорию

1. Введите ID категории из списка
2. Если по категории есть траты, бот спросит подтверждение
3. При подтверждении категория и все траты удаляются

### Объединить категории

Слияние нескольких категорий в одну с переносом всех трат и шаблонов.

**Шаги:**
1. Введите ID или названия категорий через запятую/пробел
2. Бот покажет, что будет объединено
3. Введите итоговое название
4. Все траты и шаблоны переносятся в новую категорию

**Примеры ввода:**
```
1, 3
Такси, тахи
1 3 5
```

**Case-insensitive:** `Такси`, `такси`, `ТАКСИ` — всё работает!

## 📊 Отчёты

Нажмите **Отчет** → выберите тип:

```
[ По категориям ] [ За период ]
[         Все траты           ]
[           Назад             ]
```

### По категориям

**Шаги:**
1. Выберите категорию
2. Выберите период (День / Неделя / Месяц / Квартал / Год)
3. Получите детальный отчёт

**Формат отчёта:**
```
Траты по категории 'Еда':

Продукты: 3339.00 ₸
    2026-02-10 - 1200.00 ₸
    2026-02-11 - 2139.00 ₸

Лавка: 2000.00 ₸
    2026-02-11 - 2000.00 ₸

Общая сумма: 5339.00 ₸
```

**Дополнительно:**
- 📄 Excel-файл с детализацией
- 🥧 Круговая диаграмма (pie chart)
- 📈 Stacked bar chart (для периодов > 1 дня)

### За период

**Шаги:**
1. Выберите период или введите даты вручную
2. Получите отчёт с группировкой по датам

**Формат отчёта:**
```
Траты с 04.02.2026 по 11.02.2026

10.02.2026:
    Еда:
        Лавка: 2000.00 ₸

11.02.2026:
    Еда:
        Продукты: 3339.00 ₸

    Такси:
        Яндекс: 500.00 ₸

Общая сумма: 5839.00 ₸
```

**Дополнительно:**
- 📄 Excel-файл
- 🥧 Круговая диаграмма
- 📊 **Stacked bar chart** с автоматической группировкой:
  - **День (≤31 день)** — столбики по дням
  - **Неделя (32-365 дней)** — столбики по неделям + кнопка детализации по дням
  - **Месяц (>365 дней)** — столбики по месяцам + кнопка детализации по неделям/дням

**Интерактивность:** Нажмите `📊 По дням` или `📊 По неделям` для детализации!

### Все траты

Полный нумерованный список всех записей в обратном хронологическом порядке:

```
Все траты:

1. 2026-02-11 | Еда | Продукты | 3339.00 ₸
2. 2026-02-10 | Еда | Лавка | 2000.00 ₸
3. 2026-02-10 | Такси | Яндекс | 500.00 ₸
```

### ✏️ Редактировать траты

**Шаги:**
1. Выберите период: **День / Неделя / Месяц**
2. Бот покажет нумерованный список трат за период
3. Введите номер записи
4. Бот покажет текущие данные
5. Введите новые данные в одном из форматов:
   - `Категория, Наименование, Сумма`
   - `Категория | Наименование | Цена | Количество`
   - `Категория, Сумма`
6. Запись обновляется ✅

**Новое в 0.6.0:** Поддержка обоих разделителей `,` и `|`!

### 🗑 Удалить траты

**Шаги:**
1. Выберите период: **День / Неделя / Месяц**
2. Бот покажет нумерованный список трат за период
3. Введите номер записи
4. Бот спросит подтверждение: **Да / Нет**
5. Запись удаляется ❌

## 🔁 Шаблоны повторяющихся трат

Для регулярных платежей (аренда, подписки, интернет).

Нажмите **Шаблоны** в главном меню:

```
[ Мои шаблоны ] [ Добавить шаблон ]
[ Удалить шаблон] [     Назад      ]
```

### Добавить шаблон

Нажмите **Добавить шаблон** и введите:

**Формат:** `Категория, Наименование, Сумма, День`

```
Аренда, Квартира, 150000, 5
Интернет, Билайн, 5000, 15
```

Или без наименования:

```
Подписка, 990, 1
```

**День месяца:** 1–28 (ограничено, чтобы работало в феврале)

### 🔔 Как работают напоминания

Каждый день в **9:00 по вашему часовому поясу** бот проверяет шаблоны. Если день совпадает с текущей датой, бот отправит:

> 🔔 Напоминание: Аренда — Квартира, 150 000 ₸
> Записать трату?
>
> [ ✅ Записать ] [ ❌ Пропустить ]

- **✅ Записать** — трата записывается в базу с кнопкой отмены
- **❌ Пропустить** — ничего не происходит

### Мои шаблоны

Показывает список шаблонов с ID, суммой и днём:

```
1: Аренда — Квартира, 150000 ₸, 5-го числа
2: Интернет — Билайн, 5000 ₸, 15-го числа
```

### Удалить шаблон

Введите ID шаблона из списка.

## 📈 Ежемесячное сравнение

**Автоматическая функция** — настройка не требуется!

**1-го числа каждого месяца в 9:00** (по вашему часовому поясу) бот автоматически отправляет сравнение трат с прошлым месяцем:

> 📊 Сравнение: January 2026 vs December 2025
>
> 📈 Продукты: 85 000 ₸ (+12%)
> 📉 Транспорт: 15 000 ₸ (−25%)
> ➡️ Еда: 45 000 ₸ (+0%)
> 🆕 Одежда: 30 000 ₸ (новая)
>
> Итого: 175 000 ₸ (+5% к прошлому)

**Легенда:**
- 📈 — расходы выросли
- 📉 — расходы снизились
- ➡️ — без изменений
- 🆕 — новая категория (не было в прошлом месяце)

## 💡 Советы и лайфхаки

### Для новичков:
1. **Создайте категории до начала ввода** — это упростит работу
2. **Используйте короткие названия** — `Еда` вместо `Питание и продукты`
3. **Включите уведомления** — не пропустите напоминания по шаблонам
4. **Настройте часовой пояс** — напоминания придут вовремя

### Продвинутые:
- **Нечёткий поиск** работает с порогом 55% — пишите как удобно!
- **Регистр не важен** — `Продукты`, `продукты`, `ПРОДУКТЫ` — одинаково
- **Суффиксы валют убираются** — `1200р`, `500тг`, `300₸` распознаются корректно
- **Два разделителя** — выбирайте между `,` и `|` по предпочтению
- **Excel + графики** — полный набор инструментов для анализа
- **Объединяйте категории** — упростите структуру без потери данных

### Ограничения:
- ❌ Кнопка «↩ Отменить» работает только для **последней** траты
- ⏱ День в шаблонах: **1–28** (февраль тоже должен работать!)
- 📊 Детализация графиков: максимум 2 уровня вложенности

## 🔐 Безопасность

- ✅ **HTML-экранирование** — защита от инъекций через имена категорий
- ✅ **SQL параметризация** — защита от SQL-инъекций
- ✅ **Проверка владельца** — user_id проверяется во всех операциях
- ✅ **Изоляция данных** — каждый пользователь видит только свои траты

## 🐛 Известные проблемы

- Pyrogram требует `app.run()` вместо `asyncio.run()` для работы планировщика
- Некоторые emoji могут некорректно отображаться в зависимости от клиента

## 🚀 Установка и запуск (для разработчиков)

### Требования

- Python 3.12+
- SQLite 3
- Telegram API credentials

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Diogen477/MoneyBot.git
cd MoneyBot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте `.env` файл:
```env
API_ID=your_api_id
API_HASH=your_api_hash
BOT_TOKEN=your_bot_token
```

4. Инициализируйте базу данных:
```bash
python setup_db.py
```

5. Запустите бота:
```bash
python bot.py
```

### Структура БД

**Таблицы:**
- `user_settings` — настройки пользователей (валюта, часовой пояс, последняя категория)
- `user_states` — состояния FSM для диалогов
- `categories` — категории трат
- `expenses` — записи о тратах
- `recurring_templates` — шаблоны повторяющихся трат
