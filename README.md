# MoneyBot — Telegram-бот для учёта расходов

Персональный Telegram-бот для ведения учёта трат с поддержкой категорий, отчётов, повторяющихся платежей и свободного формата ввода.

## Возможности

- **Свободный ввод трат** — пиши как удобно: `Продукты яблоки 100`, `такси 500`, `Еда 1200р`
- **Точный формат** — `Продукты, Яблоки, 100, 2` (категория, название, цена, количество)
- **Умная категоризация** — бот запоминает последнюю категорию и предлагает её для следующей траты
- **Отмена** — inline-кнопка «↩ Отменить» после каждой записи
- **Отчёты** — текст + Excel + круговая диаграмма за любой период
- **Отчёт по категории** — детализация трат внутри категории
- **Шаблоны** — повторяющиеся траты (аренда, подписки) с ежедневными напоминаниями
- **Ежемесячное сравнение** — автоматический отчёт 1-го числа: сравнение с прошлым месяцем
- **Мультивалютность** — KZT, RUB, USD, EUR, UAH, GBP, UZS, KGS

## Стек

- Python 3.12+
- [Pyrogram](https://docs.pyrogram.org/) — Telegram MTProto API
- SQLite (aiosqlite) — хранение данных
- APScheduler — планировщик задач
- matplotlib / pandas / openpyxl — отчёты

# MoneyBot — Инструкция пользователя

## Начало работы

Отправьте боту `/start`. Бот закрепит сообщение с примерами формата ввода и покажет главное меню.

## Добавление трат

### Свободный формат

Просто напишите трату как удобно:

```
Продукты яблоки 100
Такси 500
Еда пицца 1200р
Кафе кофе 800тг
```

Бот найдёт категорию по первому слову, распознает сумму и запишет трату.

### С ценой и количеством

Если указать два числа, бот посчитает сумму автоматически:

```
Продукты молоко 350 2
```

Запишет: Продукты — молоко, 350 × 2 = 700

### Точный формат (с запятыми)

```
Продукты, Яблоки, 100, 2
Такси, 500
```

### Быстрый ввод без категории

Если написать трату без категории:

```
кофе 450
```

Бот предложит записать в последнюю использованную категорию:

> Записать «кофе 450 ₸» в категорию «Еда»?
>
> [Да] [Другая]

- **Да** — записывает в предложенную категорию
- **Другая** — показывает список категорий для выбора

### Отмена траты

После каждой записи появляется кнопка **↩ Отменить**. Нажмите, чтобы удалить ошибочную трату.

## Категории

Нажмите **Категории** в главном меню:

- **Мои категории** — список всех категорий с ID
- **Добавить категорию** — введите название новой категории
- **Удалить категорию** — введите ID категории. Если по ней есть траты, бот спросит подтверждение

## Отчёты

### Общий отчёт

Нажмите **Отчет** → выберите период:

- **День** — сегодня
- **Неделя** — последние 7 дней
- **Месяц** — последние 30 дней
- **Квартал** — последние 90 дней
- **Год** — последние 365 дней
- **Ввести даты вручную** — формат: `2025-01-01 2025-01-31`

Бот отправит:
1. Текстовый отчёт с суммами по категориям
2. Excel-файл с детализацией
3. Круговую диаграмму

### Отчёт по категории

Нажмите **Отчет по категории** → выберите категорию → выберите период.

Покажет детализацию трат внутри выбранной категории.

### Все траты

Нажмите **Все траты** — полный список всех записей, отсортированный по дате.

## Шаблоны повторяющихся трат

Для регулярных платежей (аренда, подписки, интернет).

Нажмите **Шаблоны** в главном меню:

### Добавить шаблон

Нажмите **Добавить шаблон** и введите:

```
Аренда, Квартира, 150000, 5
```

Формат: Категория, Наименование, Сумма, День месяца (1–28)

Или без наименования:

```
Интернет, 5000, 15
```

### Как работают напоминания

Каждый день в 9:00 (Алматы) бот проверяет шаблоны. Если день совпадает с текущей датой, бот отправит:

> 🔔 Напоминание: Аренда — Квартира, 150 000 ₸
> Записать трату?
>
> [✅ Записать] [❌ Пропустить]

- **✅ Записать** — трата записывается в базу
- **❌ Пропустить** — ничего не происходит

### Мои шаблоны

Показывает список шаблонов с ID, суммой и днём.

### Удалить шаблон

Введите ID шаблона из списка.

## Ежемесячное сравнение

1-го числа каждого месяца в 9:00 бот автоматически отправляет сравнение трат с прошлым месяцем:

> 📊 Сравнение: January 2026 vs December 2025
>
> 📈 Продукты: 85 000 ₸ (+12%)
> 📉 Транспорт: 15 000 ₸ (−25%)
> 📈 Еда: 45 000 ₸ (+8%)
> 🆕 Одежда: 30 000 ₸ (новая)
>
> Итого: 175 000 ₸ (+5% к прошлому)

Настройка не требуется — отчёт формируется автоматически.

## Валюта

По умолчанию — тенге (₸). Для смены отправьте:

```
/currency RUB
```

Доступные валюты:

| Код | Символ |
|-----|--------|
| KZT | ₸ |
| RUB | ₽ |
| USD | $ |
| EUR | € |
| UAH | ₴ |
| GBP | £ |
| UZS | сўм |
| KGS | сом |

Текущую валюту можно проверить: `/currency`

## Советы

- Создайте категории до начала ввода трат
- Используйте короткие названия категорий для удобного свободного ввода
- Суффиксы валют (`р`, `руб`, `₸`, `тг`) автоматически убираются при парсинге
- Кнопка «↩ Отменить» работает только для последней траты — после новой записи предыдущую отменить нельзя
- День в шаблонах ограничен 1–28, чтобы работало в любом месяце
