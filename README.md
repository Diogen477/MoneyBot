# MoneyBot — Telegram-бот для учёта расходов

> Версия: 0.6.0-beta

Персональный Telegram-бот для ведения учёта трат с поддержкой категорий, отчётов, повторяющихся платежей и свободного формата ввода.

## Возможности

- **Свободный ввод трат** — пиши как удобно: `Продукты яблоки 100`, `такси 500`, `Еда 1200р`
- **Точный формат** — `Продукты, Яблоки, 100, 2` (категория, название, цена, количество)
- **Умная категоризация** — нечёткий поиск категорий, запоминание последней использованной, предложение создать новую
- **Объединение категорий** — слияние нескольких категорий в одну с переносом всех трат
- **Отмена** — inline-кнопка «↩ Отменить» после каждой записи
- **Отчёты** — по категориям, за период, все траты — с детализацией, Excel и круговой диаграммой
- **Редактирование и удаление трат** — через меню «Сервис»
- **Шаблоны** — повторяющиеся траты (аренда, подписки) с ежедневными напоминаниями
- **Ежемесячное сравнение** — автоматический отчёт 1-го числа: сравнение с прошлым месяцем
- **Мультивалютность** — KZT, RUB, USD, EUR, UAH, GBP, UZS, KGS
- **Часовой пояс** — индивидуальная настройка для каждого пользователя, напоминания приходят в локальное 9:00

## Стек

- Python 3.12+
- [Pyrogram](https://docs.pyrogram.org/) — Telegram MTProto API
- SQLite (aiosqlite) — хранение данных
- APScheduler — планировщик задач
- matplotlib / pandas / openpyxl — отчёты

# Инструкция пользователя

## Начало работы

Отправьте боту `/start`. Бот закрепит сообщение с примерами формата ввода и покажет главное меню.

## Добавление трат

### Свободный формат

Просто напишите трату как удобно:

```
Продукты яблоки 100
Такси 500
Еда пицца 1200р
Кафе кофе 800тг
```

Бот найдёт категорию по первому слову (в том числе нечётким поиском), распознает сумму и запишет трату.

### С ценой и количеством

Если указать два числа, бот посчитает сумму автоматически:

```
Продукты молоко 350 2
```

Запишет: Продукты — молоко, 350 × 2 = 700

### Точный формат (с запятыми)

```
Продукты, Яблоки, 100, 2
Такси, 500
```

### Быстрый ввод без категории

Если написать трату без категории:

```
кофе 450
```

Бот предложит записать в последнюю использованную категорию:

> Записать «кофе 450 ₸» в категорию «Еда»?
>
> [Да] [Другая]

- **Да** — записывает в предложенную категорию
- **Другая** — показывает список категорий для выбора

### Нечёткий поиск категорий

Если категория не найдена точно, бот ищет похожую. Например, если написать `Ееда 500`, а категория называется `Еда` — бот предложит:

> Категория «Ееда» не найдена, но есть «Еда». Использовать её?
>
> [✅ Да, использовать] [➕ Нет, создать новую] [◀️ Назад]

Если похожей категории нет, бот предложит создать новую.

### Отмена траты

После каждой записи появляется кнопка **↩ Отменить**. Нажмите, чтобы удалить ошибочную трату.

## Категории

Нажмите **Категории** в главном меню:

- **Мои категории** — список всех категорий с ID
- **Добавить категорию** — введите название новой категории
- **Удалить категорию** — введите ID категории. Если по ней есть траты, бот спросит подтверждение
- **Объединить категории** — введите ID или названия категорий через запятую/пробел, затем укажите итоговое название. Все траты и шаблоны будут перенесены

## Отчёты

Нажмите **Отчет** → выберите тип:

```
[ По категориям ] [ За период ]
[         Все траты           ]
[           Назад             ]
```

### По категориям

Выберите категорию → выберите период. Бот отправит детализированный отчёт:

```
Траты по категории 'Еда':

Продукты: 3339.00 ₸
    10.02.2026 - 1200.00 ₸
    11.02.2026 - 2139.00 ₸

Лавка: 2000.00 ₸
    11.02.2026 - 2000.00 ₸

Общая сумма: 5339.00 ₸
```

Плюс Excel-файл и круговая диаграмма.

### За период

Выберите период (День / Неделя / Месяц / Квартал / Год / Ввести даты вручную). Бот отправит отчёт с группировкой по датам и категориям:

```
Траты с 04.02.2026 по 11.02.2026

10.02.2026:
    Еда:
        Лавка: 2000.00 ₸

11.02.2026:
    Еда:
        Продукты: 3339.00 ₸

    Такси:
        Яндекс: 500.00 ₸

Общая сумма: 5839.00 ₸
```

Плюс Excel-файл и круговая диаграмма.

### Все траты

Полный нумерованный список всех записей:

```
Все траты:

1. 2026-02-11 | Еда | Продукты | 3339.00 ₸
2. 2026-02-10 | Еда | Лавка | 2000.00 ₸
3. 2026-02-10 | Такси | Яндекс | 500.00 ₸
```

## Сервис

Нажмите **Сервис** в главном меню:

```
[    Валюта    ] [ Часовой пояс ]
[ Редактировать траты ] [ Удалить траты ]
[   Справка   ] [    Назад     ]
```

### Валюта

Показывает текущую валюту и инструкцию по смене. Для смены отправьте:

```
/currency RUB
```

Доступные валюты:

| Код | Символ |
|-----|--------|
| KZT | ₸ |
| RUB | ₽ |
| USD | $ |
| EUR | € |
| UAH | ₴ |
| GBP | £ |
| UZS | сўм |
| KGS | сом |

### Справка

Выводит краткую справку по использованию бота (аналог `/help`).

### Часовой пояс

Показывает текущий часовой пояс и позволяет сменить его. Можно выбрать из списка популярных или ввести вручную.

Через кнопку:

**Сервис → Часовой пояс** → выберите из списка:

| Город | Пояс |
|-------|------|
| Алматы | UTC+6 |
| Москва | UTC+3 |
| Киев | UTC+2 |
| Ташкент | UTC+5 |
| Бишкек | UTC+6 |
| Дубай | UTC+4 |
| Стамбул | UTC+3 |
| Берлин | UTC+1 |
| Лондон | UTC+0 |
| Нью-Йорк | UTC-5 |

Или командой:

```
/timezone Europe/Moscow
```

По умолчанию — `Asia/Almaty`. Часовой пояс влияет на время напоминаний по шаблонам и ежемесячных отчётов — они приходят в 9:00 по вашему локальному времени.

### Редактировать траты

1. Выберите период: **День / Неделя / Месяц**
2. Бот покажет нумерованный список трат за период
3. Введите номер записи
4. Бот покажет текущие данные и попросит ввести новые в формате:
   - `Категория, Наименование, Сумма`
   - `Категория, Наименование, Цена, Количество`
   - `Категория, Сумма`
5. Запись обновляется

### Удалить траты

1. Выберите период: **День / Неделя / Месяц**
2. Бот покажет нумерованный список трат за период
3. Введите номер записи
4. Бот спросит подтверждение: **Да / Нет**
5. Запись удаляется

## Шаблоны повторяющихся трат

Для регулярных платежей (аренда, подписки, интернет).

Нажмите **Шаблоны** в главном меню:

### Добавить шаблон

Нажмите **Добавить шаблон** и введите:

```
Аренда, Квартира, 150000, 5
```

Формат: Категория, Наименование, Сумма, День месяца (1–28)

Или без наименования:

```
Интернет, 5000, 15
```

### Как работают напоминания

Каждый день в 9:00 по часовому поясу пользователя бот проверяет шаблоны. Если день совпадает с текущей датой, бот отправит:

> 🔔 Напоминание: Аренда — Квартира, 150 000 ₸
> Записать трату?
>
> [✅ Записать] [❌ Пропустить]

- **✅ Записать** — трата записывается в базу
- **❌ Пропустить** — ничего не происходит

### Мои шаблоны

Показывает список шаблонов с ID, суммой и днём.

### Удалить шаблон

Введите ID шаблона из списка.

## Ежемесячное сравнение

1-го числа каждого месяца в 9:00 (по часовому поясу пользователя) бот автоматически отправляет сравнение трат с прошлым месяцем:

> 📊 Сравнение: January 2026 vs December 2025
>
> 📈 Продукты: 85 000 ₸ (+12%)
> 📉 Транспорт: 15 000 ₸ (−25%)
> 📈 Еда: 45 000 ₸ (+8%)
> 🆕 Одежда: 30 000 ₸ (новая)
>
> Итого: 175 000 ₸ (+5% к прошлому)

Настройка не требуется — отчёт формируется автоматически.

## Советы

- Создайте категории до начала ввода трат
- Используйте короткие названия категорий для удобного свободного ввода
- Суффиксы валют (`р`, `руб`, `₸`, `тг`) автоматически убираются при парсинге
- Кнопка «↩ Отменить» работает только для последней траты — после новой записи предыдущую отменить нельзя
- Для редактирования и удаления старых трат используйте **Сервис**
- Часовой пояс по умолчанию — Алматы (UTC+6). Измените через **Сервис → Часовой пояс** или `/timezone`
- День в шаблонах ограничен 1–28, чтобы работало в любом месяце
